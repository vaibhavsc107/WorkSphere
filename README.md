
# WorkSphere

Enterprise HR & Workforce Management System.

## Project Overview

WorkSphere is a full-stack HR management platform
developed using Java Spring Boot, React.js and MySQL.

## Technology Stack

### Frontend
- React.js
- JavaScript
- Vite
- Axios
- React Router
- Tailwind CSS

### Backend
- Java 21
- Spring Boot
- Spring Security
- JWT
- Spring Data JPA
- Hibernate
- Maven

### Database
- MySQL 8

## Main Modules

- Authentication and Authorization
- Employee Management
- Department Management
- Attendance Management
- Leave Management
- Payroll Management
- Performance Management
- Reports and Analytics
